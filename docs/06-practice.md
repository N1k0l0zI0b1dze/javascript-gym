# Chapter 6 — პრაქტიკული მაგალითები

## საწყისი მონაცემები

```js
const users = [
  {
    id: 1,
    name: "Nika",
    age: 23,
    country: "Georgia",
    isActive: true,
  },
  {
    id: 2,
    name: "Luka",
    age: 19,
    country: "Georgia",
    isActive: false,
  },
  {
    id: 3,
    name: "John",
    age: 27,
    country: "USA",
    isActive: true,
  },
  {
    id: 4,
    name: "Marie",
    age: 35,
    country: "France",
    isActive: true,
  },
  {
    id: 5,
    name: "Ana",
    age: 29,
    country: "Georgia",
    isActive: true,
  },
];
```

---

# ნაწილი A — `map`

## ამოცანა 1

მიიღე ყველა user-ის სახელების Array.

მოსალოდნელი შედეგი:

```js
["Nika", "Luka", "John", "Marie", "Ana"]
```

## ამოცანა 2

მიიღე ასეთი ტექსტები:

```js
[
  "Nika is 23 years old",
  "Luka is 19 years old",
  ...
]
```

## ამოცანა 3

ყველა user-ს დაუმატე:

```js
role: "user"
```

ძველი ობიექტები არ შეცვალო.

---

# ნაწილი B — `filter`

## ამოცანა 1

დატოვე მხოლოდ აქტიური users.

## ამოცანა 2

დატოვე მხოლოდ 25 წელზე უფროსი users.

## ამოცანა 3

დატოვე მხოლოდ აქტიური users საქართველოდან.

## ამოცანა 4

დატოვე users, რომელთა სახელი 4 ასოზე მეტია.

---

# ნაწილი C — `reduce`

## ამოცანა 1

დათვალე users-ის ასაკების ჯამი.

## ამოცანა 2

იპოვე ყველაზე ასაკოვანი აქტიური user.

უნდა დაბრუნდეს მთელი ობიექტი.

## ამოცანა 3

დათვალე აქტიური users თითოეული ქვეყნის მიხედვით.

მოსალოდნელი ფორმა:

```js
{
  Georgia: 2,
  USA: 1,
  France: 1
}
```

## ამოცანა 4

დათვალე რამდენი user არის აქტიური და რამდენი არააქტიური.

მოსალოდნელი ფორმა:

```js
{
  active: 4,
  inactive: 1
}
```

## ამოცანა 5

შექმენი user-ების ობიექტი `id`-ების მიხედვით:

```js
{
  1: {
    id: 1,
    name: "Nika",
    ...
  },
  2: {
    id: 2,
    name: "Luka",
    ...
  }
}
```

# ნაწილი D — კომბინირებული ამოცანები

## ამოცანა 1

მიიღე მხოლოდ აქტიური users-ის სახელები.

გამოიყენე:

```txt
filter → map
```

## ამოცანა 2

მიიღე საქართველოდან მყოფი აქტიური users-ის საშუალო ასაკი.

ლოგიკური ეტაპები:

```txt
filter
→ reduce
→ საშუალოს გამოთვლა
```

## ამოცანა 3

იპოვე ყველაზე ასაკოვანი user თითოეულ ქვეყანაში.

მოსალოდნელი ფორმა:

```js
{
  Georgia: {
    name: "Ana",
    age: 29,
    ...
  },
  USA: {
    name: "John",
    age: 27,
    ...
  },
  France: {
    name: "Marie",
    age: 35,
    ...
  }
}
```
