1. Syntax Parser — სინტაქსური ანალიზატორი
   ლექტორის განმარტება:
   A program that reads your code and determines what it does and if its grammar or syntax is valid.

პროგრამა, რომელიც კითხულობს შენს კოდს, აანალიზებს მის სტრუქტურას და ამოწმებს, შეესაბამება თუ არა ის ენის გრამატიკულ წესებს.

2. Lexical Environment — ლექსიკური გარემო
   ლექტორის განმარტება:
   Where something sits physically in the code you write.

ანუ მნიშვნელობა აქვს იმას, თუ სად არის რაღაც დაწერილი შენს კოდში და რა გარემოცვაში იმყოფება ის.

სიტყვა Lexical დაკავშირებულია სიტყვებთან, გრამატიკასა და ენის სტრუქტურასთან.

3. Execution Context — შესრულების კონტექსტი
